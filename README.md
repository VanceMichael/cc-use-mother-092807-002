# 口岸食品准入查验与退运销毁闭环

贯通进口食品企业注册、货批查验、样品检测和退运销毁。

## 参与方与事实

主要参与方包括海关食品监管人员、境外生产企业、进口商、实验室人员、退运与销毁执行单位。领域资料记录以下已经确认的事实：

- 天津口岸前8个月进出口食品总值1097.9亿元
- 天津海关完成境外生产企业注册审核和检查任务
- 前8个月查获未准入境食品886批次并实施退运或销毁

## 业务约束

- 境外企业和产品资格
- 箱货与食品批次
- 抽样检测链
- 放行和处置
- 整改与风险预警

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/news_context_002.py` 负责读取和校验这些资料。

## 准入查验服务

`src/inspection/` 在上述领域边界内提供可运行的准入查验闭环：

- `models.py`：状态枚举与货量、摘要等纯函数规则
- `store.py`：JSON 存储，整库原子落盘，支持重启恢复
- `auth.py`：角色与履职范围授权（海关、取样人、实验室、处置单位、企业、跨部门协查）
- `service.py`：企业注册与产品资格、规则换版、舱单箱货与拆批、温控、查验任务、
  样品链与复检、检测结论、扣留/放行/退运/销毁决定、处置证明、整改、
  渠道回执幂等与异文暂停、断点恢复与决定依据还原
- `errors.py`：领域异常（校验失败、冲突、越权、终局不可覆盖、回执冲突）

关键不变量（详见 `docs/domain-rules.md`）：规则换版不追溯历史决定；
抽样拆分与复检保持货量与样品去向守恒；整票扣留未缩窄前不得局部放行；
放行/退运/销毁只增不改并固化资格、规则、检测、温控和批准依据快照；
同一回执重送返回原结果，同编号异文暂停相关批次；企业只能查看本企业材料，
取样人不能独自确认最终合格。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
